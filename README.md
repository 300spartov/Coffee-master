# Coffee-master
Приложение для заметок о кофе, записи рецептов и их контроля

## Структура проєкту

```
src/index.html        — шаблон сторінки: <head>, CSS-лінки, каркас .app, <div data-include="..."> і <script src> у потрібному порядку
src/core/             — спільне: i18n, дані/DB, стан S + save, утиліти, оверлеї, роутер (showScr),
                        автодоповнення, Supabase-синхронізація, boot.js (старт застосунку — підключається останнім)
src/features/<name>/  — окремий екран/фіча: <name>.html, <name>.css, <name>.js
build.py              — збирає кореневий index.html: підставляє HTML-партіали з src/
index.html            — ЗГЕНЕРОВАНИЙ файл (відкривається подвійним кліком, деплоїться на Vercel). Руками не правити.
```

Після зміни будь-якого `.html` у `src/` — перезберіть і закомітьте `index.html`:

```
python3 build.py
```

Зміни в `.js` / `.css` підхоплюються без збірки (вони підключені окремими файлами).

- Новий JS-файл — `<script src>` у `src/index.html` (порядок важливий, `src/core/boot.js` — останній).
- Новий CSS — `<link>` у `src/index.html` (порядок повторює оригінальний каскад).
- Новий HTML-партіал — `<div data-include="src/..."></div>` окремим рядком у потрібному місці.
